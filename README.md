# Torch Passers of SPLORR!!

An absurd, menu-driven succession game for [AI Browser Game Jam 5](https://itch.io/jam/ai-jam-5) (theme: TORCH). Carry a torch through eight generations; one thing and one grudge can be handed down each time, and neither arrives the same.

Play: https://thegrumpygamedev.itch.io/torch-passers-of-splorr

Written in Odin and compiled to WebAssembly, with Claude Code. See [CLAUDE.md](CLAUDE.md) for the commands, layout and balance notes, and [PLAN.md](PLAN.md) for the design.

Credits: faces from the [Urizen 1-bit tileset](https://vurmux.itch.io/urizen-onebit-tileset) by vurmux (CC0); cover lettering in Public Pixel Font by GGBotNet (CC0); sound effects generated with [jsfxr](https://sfxr.me).
